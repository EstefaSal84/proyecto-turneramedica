Proyecto: Turnera Médica
Aplicación web desarrollada como práctica integradora del curso de JavaScript y desarrollo frontend. Permite gestionar turnos médicos de manera interactiva, mostrando disponibilidad por fecha y ofreciendo confirmaciones visuales al usuario.
El proyecto incluye:

HTML para la estructura básica.

CSS con estilos profesionales y responsivos.

JavaScript para la lógica de carga de turnos, reserva y notificaciones.

Uso de librerías externas: Toastify y SweetAlert.
Este repositorio contiene todos los archivos del proyecto:

index.html

style.css

app.js

turnos.json

La aplicación permite:

Seleccionar fecha y visualizar turnos disponibles/ocupados.

Reservar turnos con confirmación visual.

Recibir alertas y notificaciones dinámicas

Reflexión Final
La realización de este proyecto representó una instancia integradora en la que pude aplicar de manera práctica los conocimientos adquiridos a lo largo del curso de JavaScript y desarrollo frontend. El desafío de construir una aplicación interactiva me permitió comprender la importancia de combinar conceptos fundamentales —como la manipulación del DOM, el asincronismo y los métodos funcionales de arrays— en un contexto realista y cercano al trabajo profesional.
Durante el desarrollo, enfrenté la necesidad de estructurar el código con claridad, eliminar prácticas limitantes como el uso de prompt o alert, y recurrir a librerías externas para enriquecer la experiencia del usuario. Estos aspectos me ayudaron a valorar la importancia de las buenas prácticas de programación, la organización del proyecto y la documentación clara para facilitar la comprensión de la lógica implementada.
Asimismo, el uso de archivos JSON y la integración con fetch reforzaron mi entendimiento sobre la gestión de datos y la comunicación entre diferentes componentes de una aplicación web. Este aprendizaje resulta especialmente valioso para escenarios reales en los que se requiere trabajar con APIs y datos dinámicos.
En conclusión, este proyecto no solo consolidó mis conocimientos técnicos, sino que también me permitió desarrollar competencias transversales como la planificación, la resolución de problemas y la adaptación a nuevas herramientas. Considero que la experiencia adquirida constituye una base sólida para seguir avanzando en el desarrollo frontend y afrontar con mayor seguridad proyectos más complejos en el futuro.
